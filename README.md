# LeetCode Daily 🧩

A collection of my **daily LeetCode solutions**, written primarily in **C++**.

This repository is a record of my journey to improve my **Data Structures & Algorithms**, problem-solving ability, and consistency through regular LeetCode practice.

## 🎯 Goal

The goal of this repository is simple:

**Solve at least one LeetCode problem every day.**

Rather than organizing problems by topic, the repository follows my **daily solving timeline**, making it a record of my progress over time.

## 📅 Daily Progress

Each solution represents a problem I worked on during my LeetCode practice.

The problems may cover different topics and difficulty levels, including:

* Easy
* Medium
* Hard

Topics can vary from day to day depending on the problem.

## 💻 Language

**C++**

Solutions use standard C++ and STL wherever appropriate.
